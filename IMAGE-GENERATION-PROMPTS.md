## 📊 IMAGE SPECIFICATIONS

**For best results when generating with ChatGPT/DALL-E:**

1. **Format:** Request "landscape orientation, 16:9 aspect ratio" for hero images
2. **Format:** Request "4:3 aspect ratio" for gallery thumbnails
3. **Style:** Always include "photorealistic, professional photography, high quality"
4. **Lighting:** Specify "natural daylight" or "warm professional lighting"
5. **Color:** Mention "warm color palette with orange accents" to match brand
6. **Quality:** Include "4K resolution, commercial photography quality"

**Post-Processing Tips:**
- Adjust brightness to maintain visibility
- Enhance contrast slightly for web display
- Optimize file size for web (compress to ~200-500KB)
- Save as .jpg for photographs
- Maintain aspect ratios as designed

After generating and saving images, update the URLs in:
- `app/services/page.tsx`
- `app/services/installation/page.tsx`
- `app/services/repair/page.tsx`
- `app/door-types/page.tsx`
- `app/gallery/page.tsx`
- `components/home/*.tsx`

Replace Unsplash URLs with local paths:
```tsx

// After:
image: "/service-installation.jpg"
```
