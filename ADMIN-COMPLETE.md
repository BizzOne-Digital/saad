## 🔐 Authentication

### Current Setup:
- Client-side authentication
- localStorage session storage
- Protected routes
- Login/logout functionality

### Login Flow:
1. Enter credentials at `/admin/login`
2. Validated against `.env` defaults
3. Auth token stored in localStorage
4. Redirect to dashboard
5. All pages check for auth
6. Logout clears token
